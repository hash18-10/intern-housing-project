# 🏠 Intern Housing Price Prediction Project

This is a full-stack Data Science project that analyzes housing data and predicts house prices based on user input. It includes Exploratory Data Analysis (EDA), Inferential Statistics, and a trained Machine Learning model with a web-based interface.

---

## 📊 Features

- Descriptive Statistics (EDA)
- Inferential Statistical Trends
- House Price Prediction using Linear Regression
- User interface with three pages:
  - Descriptive Stats
  - Inferential Stats
  - Model Prediction

---

## 🧠 Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python (Flask)
- **Model**: Linear Regression (scikit-learn)
- **EDA & Plots**: Pandas, Matplotlib, Seaborn
